# Hobby Finder — Chat Preview (Single-file React)

**A single-file React preview** (CDN React + Babel) that runs entirely in the browser.  
Features:
- Chat-like UI with suggestions and rich hobby cards.
- 10-question quiz flow + free-text preference detection.
- Surprise Me, Save Favorites (localStorage), and fun facts.
- Client-side CSV import: auto-load CSV from GitHub raw URL via `?csv=RAW_URL` or use Upload/Load-from-URL UI to import a CSV.
- Works without build tools — drop `index.html` in a GitHub Pages repo and you're live.
